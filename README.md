# Realm Toggle (realm-toggle)

Плагин для AngelOS, который добавляет быстрое переключение между раем и адом.

## Особенность

Плагин активируется **только после первого полноценного прохождения ада**.

До этого момента он не вмешивается в обычную механику AngelOS.

После прохождения ада кнопка плагина позволяет переключаться:

`Рай ⇄ Ад`

Возвращение из ада через плагин **не увеличивает счётчик возвращений AngelOS**.

При этом сам AngelOS и его системные файлы не изменяются — вся логика находится внутри этого плагина.

## Установка / Install

Через Community Store или вручную:

    cp -a realm-toggle ~/.config/angelos/plugins/realm-toggle

Затем перезагрузите AngelOS и включите плагин в Settings → Plugins.

## Требования / Requirements

Нужна версия AngelOS с режимами «рай» и «ад» и сервисом `Angel`.

Плагин использует состояние прохождения ада из Story AngelOS для определения, был ли хотя бы один завершённый маршрут ада.

## Как работает / How it works

- До первого завершённого прохождения ада плагин не переключает измерения.
- После прохождения ада плагин разрешает переключение между раем и адом.
- Возврат в рай сохраняет исходное значение `Story.player.returns`.
- AngelOS не модифицируется.
- Сеть и внешние программы для работы плагина не требуются.
